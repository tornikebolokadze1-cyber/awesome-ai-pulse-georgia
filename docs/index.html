MCP server & CLI

ჰკითხე კოლექციას შენი AI ასისტენტიდან

აღარ გჭირდება GitHub-ის გადაქოქვა. დააკავშირე MCP server და AI პირდაპირ ამ კოლექციიდან მოგიძებნის — ან გამოიყენე aipulse CLI ტერმინალში.

~/.config — MCP (Claude Code · Cursor) 
{
  "mcpServers": {
    "aipulsegeorgia": {
      "command": "npx",
      "args": ["-y", "@aipulsegeorgia/mcp-server"]
    }
  }
}
terminal — aipulse CLI 
# npx-ით, ინსტალაციის გარეშე
$ npx -p @aipulsegeorgia/mcp-server aipulse search "rag memory"
$ aipulse list --category coding --limit 10
$ aipulse get aider
$ aipulse stats

  • get_repo · stats — კონკრეტული რეპო ან მთლიანი სტატისტიკა.
  • მუშაობს Claude Code, Cursor, Codex, Claude.ai-სა და ნებისმიერ MCP კლიენტთან.
